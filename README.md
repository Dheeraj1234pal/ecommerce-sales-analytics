#E-Commerce Sales Analytics Dashboard

## 📊 Project Overview

This project presents an interactive **E-Commerce Sales Analytics Dashboard** created in Microsoft Excel.

The dashboard analyzes sales performance, customer demographics, order channels, product demand, delivery performance, customer satisfaction, and geographic distribution.

The project is designed to demonstrate practical **data analysis, Excel dashboarding, KPI reporting, and data visualization** skills.

## 🎯 Objectives

* Analyze overall sales and order performance
* Monitor key business KPIs
* Understand customer demographics
* Compare different order channels
* Identify popular products
* Analyze order quantities
* Measure delivery performance
* Evaluate customer satisfaction
* Visualize customer geographic distribution

## 📌 Key KPIs

The dashboard includes:

* Total Orders
* Total Quantity
* Total Amount
* Average Customer Rating
* Average Days to Deliver

The displayed dashboard also provides breakdowns by gender, order mode, product, delivery time, month, and location.

## 📊 Dataset

The dataset contains e-commerce transaction information including:

* Transaction ID
* Product
* Quantity
* Unit Price
* Amount
* Order Date
* Ship Date
* Customer Gender
* Order Mode
* Customer Rating
* State
* County
* Delivery Days

Additional calculated fields are used for dashboard analysis.

## 🔍 Key Analysis Areas

The dashboard explores questions such as:

1. How many orders were placed?
2. What is the total quantity sold?
3. What is the total sales amount?
4. Which products have the highest sales/quantity?
5. Which order channels are being used?
6. What is the customer gender distribution?
7. How satisfied are customers?
8. How long does it take to deliver orders?
9. Where are customers located?
10. How does order performance vary across different categories?
